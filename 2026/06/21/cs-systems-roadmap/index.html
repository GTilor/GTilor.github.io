CS & Systems Roadmap

使用说明：本路线图专用于每天早上的【白刃战区】（建议 3-4 小时）。这里没有花哨的 AI 算法，只有最残酷的 C++ 指针、内存分配、段错误与并发死锁。它是为了在你下午搞大模型时，为你提供无可挑剔的系统级火力支援。

🎯 核心内功心法 (特种兵学习法)

在执行下方任何一个模块时，必须严格遵守以下四条铁律：

  1. 微缩法则 (Nano Project)：绝不一上来就看庞大的工业源码（如 Linux, Nginx）。一切从 1000 行以内的微缩版项目（如 Pintos, 简易线程池）开始，看懂后直接白板复写。
  2. 破坏法则 (Fork & Hack)：看代码不如改代码。Fork 下来后，故意删掉里面的并发锁，引发 Race Condition（竞态条件），亲眼看一次系统崩溃。
  3. 输出法则 (Extreme Output)：每天遇到重大 Bug，必须产出一篇 Markdown 笔记。画出它的内存架构图（Mermaid/ASCII），放上核心代码，记录你被惩罚的过程。
  4. 大脑隔离法：早上看这份文档时，绝对不要去想下午的 AI 模型公式。全神贯注于机器的物理极限。

🗺️ 突击路线图 (从算法到系统)

阶段零：Git + Linux 命令行底座 (W0，1 周)

目标：掌握所有后续项目的工具链底座。不会 Git 和 Linux 命令行，后面所有 Nano Project 都会卡在工具上而不是知识上。这一周不是"学一门课"，而是"把刀磨快"。

  • 理论执行：
    • Git（2-3 天）：
      • 精读《Pro Git 中文版》前 3 章：https://git-scm.com/book/zh/v2
      • 完成 Learn Git Branching 交互式全部基础关卡：https://learngitbranching.js.org/?locale=zh_CN
      • 重点掌握：init/add/commit/push/pull/clone、branch/merge/rebase、remote、stash、log/diff/blame、.gitignore、PR 流程、fork + upstream 同步
    • Linux 命令行（3-4 天）：
      • 看完 MIT Missing Semester 前 5 讲：https://missing.csail.mit.edu/
        1. Course overview + The Shell
        2. Shell Tools and Scripting
        3. Editors (Vim)
        4. Data Wrangling
        5. Command-line Environment
      • 重点掌握：bash 基础、文件权限（chmod/chown）、grep/find/awk/sed、管道与重定向、ssh/scp/rsync、tmux/screen、ps/top/kill、包管理（apt/brew）、环境变量、curl/wget
  • Nano Project 实战：
    • 造轮子 0.1：Git 仓库全流程。用 Git 管理自己的学习笔记仓库，完成：创建本地仓库 → 分支开发 → rebase 合并 → 推送到 GitHub → 创建 PR。进阶：fork 一个开源项目（如 karpathy/nanoGPT），克隆下来，修一个 typo 或补一段 README，提一个 PR（哪怕被拒，走完流程就是胜利）。
    • 造轮子 0.2：远程开发环境。用 SSH 连接一台远程 Linux 服务器（阿里云/腾讯云学生机，或本地 WSL2），在 tmux 中完成以下任务链：
      1. 编译运行一个 C++ Hello World（g++ hello.cpp -o hello && ./hello）
      2. 用 grep -r "TODO" . | wc -l 统计某项目里的 TODO 数量
      3. 用 find . -name "*.cpp" -exec grep -l "main" {} \; 找出所有含 main 的 cpp 文件
      4. 写一个 bash 脚本，自动备份某目录到另一个目录并加时间戳
      5. 用 ssh-keygen 配置免密登录，用 scp 传文件
  • 学习资源：
    • 网课：MIT Missing Semester（https://missing.csail.mit.edu/）—— 正是为你这种"会编程但没系统学过命令行"的人设计，每讲 1 小时，共 11 讲，前 5 讲必看
    • 交互式：Learn Git Branching（https://learngitbranching.js.org/?locale=zh_CN）—— 可视化 Git 分支操作，闯关式学习，比看文档快 10 倍
    • 书籍：《Pro Git 中文版》（https://git-scm.com/book/zh/v2，免费在线，前 3 章必读）、《The Linux Command Line》（William Shotts，免费 PDF：http://linuxcommand.org/tlcl.php）
    • 速查工具：tldr（brew install tldr，命令速查，比 man 实用）、gh-cli（GitHub 官方命令行，你已在用）
    • 可选增强：oh-my-zsh（shell 增强）、fzf（模糊查找）、ripgrep（比 grep 快 10 倍）
  • 量化验收：
    • Git：不查文档，能在 5 分钟内完成"创建分支 → 修改 → commit → rebase → push → 提 PR"全流程
    • Linux：能用一行管道命令完成"找出某目录下所有 .cpp 文件中包含 TODO 的行，按文件分组统计数量，排序后输出 top 10"
    • 综合：能在远程服务器上用 tmux 保持会话，断开 SSH 重连后工作不丢失

阶段一：C++ 复习强化与算法绞肉机 (前 2-3 周)

目标：你半年前学过 C++ 但忘了，这一阶段不是从零学，而是复习 + 强化 + 用算法题强行激活肌肉记忆。参考 lvy010 的 Algo-Atlas 方法：系统搭框架 → 定期复习 → 刷题练习。

  • 执行（三段式，参考 lvy010/Algo-Atlas）：
    • Part 1 系统搭框架（快速过一遍，唤醒记忆）：
      • 复习《C++ Primer》第 5 版核心章节：第 2 章（变量/类型）、第 3 章（string/vector）、第 5 章（语句）、第 6 章（函数）、第 7 章（类）、第 12 章（动态内存）、第 13 章（拷贝控制）、第 16 章（模板）
      • 重点激活：std::vector / std::unordered_map / std::string 的常用接口、迭代器失效问题、智能指针（std::shared_ptr / std::unique_ptr / std::weak_ptr）的所有权语义、深拷贝 vs 浅拷贝、RAII、移动语义（std::move / 右值引用 / 完美转发）
    • Part 2 刷题练习（核心，每天 2-3 小时）：
      • 按 lvy010 推荐的灵神题单专题刷题，不要随机刷：https://leetcode.cn/discuss/post/3141566/ru-he-ke-xue-shua-ti-by-endlesscheng-q3yd/
      • 新手村 8 步通关路线（先完成难度分 ≤1700 的题）：
        1. 编程入门题单（跳过数据库题）
        2. 滑动窗口（定长/不定长）
        3. 二分算法（二分答案选做）
        4. 数据结构（前缀和/栈/队列/堆）
        5. 链表、树、回溯（二叉树 DFS，为 DP 铺垫）
        6. 网格图（DFS 进一步理解递归）
        7. 回溯（进一步理解递归）
        8. 动态规划（至少 100 道才算入门，难度分可放宽到 ≤2000）
      • 用 C++ 写，强行记忆 STL 接口和反人类语法
    • Part 3 定期复习（lvy 心得）：
      • “复习是随时都可以做的事情，手机看代码、给代码做注释，就像和代码二次对话一样“
      • 每周末把本周题目用 xmind 画一张导图，按题型归类套路
  • 笔记工具栈（直接抄 lvy010）：
    • Typora：Markdown 主力，所有笔记 .md 开源到自己的 GitHub
    • draw.io：画图，“思考如何让别人看懂=帮自己理解“
    • xmind：导图梳理解题套路（如区间贪心类题型的合并/重叠/射箭模式）
    • Goodnotes（iPad）：写代码前手绘模拟（如 N 皇后的决策树），写代码后梳理状态转移
    • LICEcap：录屏 gif 演示算法过程（如贪心的局部最优推进）
    • VSCode LeetCode 插件：配置调试环境，“让坐在电脑前刷题变得更快乐“
  • 学习资源：

    • 书籍：《C++ Primer 中文版》第 5 版（复习用，按上面章节跳读，不要从头读）、《Hello 算法》C++ 版（https://www.hello-algo.com/，动画图解，查漏补缺）

    • 网课：侯捷 C++ 面向对象高级编程（B 站，讲 STL 源码极佳，适合复习时看）、《Cherno C++》（B 站/YouTube，每集 10-20 分钟，工程视角）

    • 刷题平台：LeetCode（https://leetcode.cn/）+ LeetCodeRating 插件（显示周赛难度分，scriptcat 脚本 2778）

    • 题单：灵神题单（上面链接，核心）、LeetCode HOT 100（https://leetcode.cn/studyplan/top-100-liked/，面试冲刺用）

    • 参考仓库：

      • lvy010/Algo-Atlas（⭐293，C++ 算法笔记 + 题单，可直接对照学习，150+ 题题解）
      • lvy010/cpp-sandbox（C++ 库学习沙盒：STL/多媒体/网络/UI，看别人怎么系统学 C++ 库）

    • 数据范围 → 时间复杂度表（灵神总结，刷题必备）：

      数据范围 允许复杂度 适用算法
      n≤10 O(n!) 回溯、暴力
      n≤20 O(2ⁿ) 状态压缩 DP
      n≤100 O(n³) 三重循环 DP、Floyd
      n≤1000 O(n²) 二重循环 DP、背包
      n≤10⁵ O(nlogn) 大多数题目
      n≤10⁶ O(n) 线性 DP、滑动窗口
  • 量化验收（参考 lvy010 标准）：
    • LeetCode 完成 150+ 题（灵神新手村 8 步通关 + HOT 100 核心）
    • DP 至少 100 道（lvy 原话：“至少要做 100 道才算入门“）
    • 能白板手写 std::shared_ptr 简化实现（引用计数 + 析构 + 线程安全考虑）
    • 能解释 std::move、右值引用、完美转发（面试必问）
    • 能正确分析每道题的时间和空间复杂度（lvy 引用：“LeetCode 击败 xx% 对新手无意义，能分析复杂度才是真本事“）
    • 产出：一份自己的算法笔记仓库（fork Algo-Atlas 结构），按题型整理套路

阶段二：深入理解计算机系统 OS (第 4-6 周)

目标：理解代码是如何变成机器指令，并且在内存中运行的。这是你以后写底层算子的地基。参考 lvy010/linux-lab 的三部分结构：OSTEP 读书笔记 + 内核机制实验 + 专栏配套代码。

  • 理论执行（三部分，参考 lvy010/linux-lab）：
    • Part 1 OSTEP 读书笔记 + 可运行演示（对应 lvy 的 csapp_os_code/）：
      • 精读《CSAPP》第 3 版核心章节：第 2/3 章（数据表示/机器级表示）、第 6 章（存储器层次）、第 8 章（异常控制流）、第 9 章（虚拟内存）、第 12 章（并发编程）
      • 配合读《OSTEP》（Operating Systems: Three Easy Pieces，免费在线 http://ostep.org/），三大部分：虚拟化（进程/调度/多核）、并发（线程/锁/信号量/管程）、持久化（文件系统/日志/崩溃一致性）
      • 每个概念写一个可运行演示（学 lvy 的做法）：KVM 虚拟机最小实现、Mandelbrot 渲染（OpenMP/CUDA）、锁依赖追踪、ThreadSanitizer 竞态检测、OverlayFS 演示、cgroups 观测脚本
    • Part 2 Linux 内核机制实验（对应 lvy 的 linux-core/，三个深度项目）：
      • 实验 1：IPC 全机制学习（管道/消息队列/共享内存/信号量/Socket，每个都有可运行 demo + README + 测试用例）
      • 实验 2：TUN 设备网络工具包（虚拟网卡/路由转发/防火墙规则/简易 VPN Server）
      • 实验 3：C++ 智能指针实验（shared_ptr/unique_ptr/weak_ptr、循环引用、线程安全，与阶段一的 C++ 复习呼应）
    • Part 3 专栏配套代码（对应 lvy 的 linux-study/，按时间组织）：
      • 写简易 Shell、HTTP 服务器、TCP 服务器、线程池、UDP 聊天系统、epoll 服务器
      • 每个代码都配套一篇 Markdown 笔记，画内存架构图（Mermaid/ASCII）
  • Nano Project 实战：
    • 造轮子 1：写一个高并发线程池 (Thread Pool)。学会使用 std::mutex, condition_variable。
    • 造轮子 2：写一个内存池 (Memory Pool)。接管 C++ 的 new 和 delete，告别内存碎片与泄露。
  • 学习资源：

    • 书籍：

      • 《CSAPP》第 3 版（必读：第 2/3/6/8/9/12 章）
      • 《OSTEP》（免费在线 http://ostep.org/，比 CSAPP 更聚焦 OS 本身，lvy 的 linux-lab 就是基于此）

    • 网课：

      • CMU 15-213 CSAPP 官方课程（https://www.cs.cmu.edu/~213/，B 站有中文字幕版，Bryant 教授主讲，神级课程）
      • MIT 6.S081 Operating Systems（https://pdos.csail.mit.edu/6.S081/2020/，xv6 配套课程，B 站有中文字幕）

    • Lab 实践（CSAPP 官方 Lab，强烈推荐动手做）：

      • Data Lab（位运算）
      • Bomb Lab（逆向工程，最爽的 Lab）
      • Attack Lab（栈溢出攻击）
      • Cache Lab（缓存优化）
      • Malloc Lab（自己实现 malloc/free，与造轮子 2 呼应）

    • OS 内核：

      • mit-pdos/xv6-riscv（https://github.com/mit-pdos/xv6-riscv，MIT 教学操作系统，1 万行代码，可读性极强）
      • 网课：MIT 6.S081（上面已列，xv6 配套）

    • 参考仓库：

      • lvy010/linux-lab（直接对照学习：OSTEP 笔记 + 内核实验 + 50+ 篇专栏代码，86 commits，结构清晰）
      • lvy010/linux-core（Linux 内核源码阅读注释，进行中）
      • lvy010/rCore（用 Rust 写 OS，可对照，但你暂不学 Rust）

    • lvy 的学习时间表参考（来自 linux-lab 专栏）：

      阶段 lvy 用时 主题
      Linux 基础 2024.06 命令行、权限、Vim、Makefile、Git
      进程与线程 2024.06-08 fork、exec、POSIX 线程、锁、死锁
      网络编程 2024.08-10 Socket、UDP/TCP、HTTP、epoll
      协议深入 2024.10-2025.05 TCP 滑动窗口、IP 分片、ARP/DNS、IO 模型
      工具实践 2024.12-2025.01 perf 性能分析、双系统安装
  • 量化验收（参考 lvy010/linux-lab 标准）：
    • 完成 CSAPP 至少 3 个 Lab（推荐 Bomb + Malloc + Cache）
    • 线程池：能跑 1000 个任务无死锁，用 valgrind 检查无内存泄漏
    • 内存池：对比 new/delete 与自实现内存池的吞吐，写出 benchmark 报告
    • 能画出进程虚拟地址空间布局图，解释页表、TLB、Cache 层次关系
    • 产出：一个类似 lvy010/linux-lab 的仓库，含 OSTEP 笔记 + 3 个内核实验 + 专栏配套代码（每个都有 README + 编译脚本 + 测试用例）
    • lvy 原话印证：“Linux 系统层面的积累——进程调度、IPC、网络协议栈、设备驱动——对理解 AI 基础设施（GPU 调度、高性能通信、内核态优化）仍然是不可替代的基础“

阶段三：计算机网络与分布式雏形 (第 7-8 周)

目标：当内存和并发搞定后，你需要让不同的机器通信。这是分布式训练大模型（DDP）的前置科技树。

  • 理论执行：
    • 理解 TCP/UDP，理解什么是 Epoll / Reactor 模式（多路复用）。
  • Nano Project 实战：
    • 造轮子 3：手搓简易 RPC 框架（Remote Procedure Call）。像 lvy010 一样，用 C++ 和 JSON 序列化，写一个能让两台电脑互相调用函数的框架。
    • 拔高（选修）：粗读陈硕的 Muduo 网络库核心源码，理解大牛是怎么写 C++ 服务器的。
  • 学习资源：
    • 书籍：
      • 《计算机网络：自顶向下方法》第 7 版（Kurose & Ross，从应用层讲到底层，比国内教材好 10 倍）
      • 《Linux 多线程服务端编程》（陈硕，muduo 作者，C++ 网络编程圣经）
      • 《TCP/IP 详解 卷 1》（选读，当字典查）
    • 网课：
      • 中科大郑烇《计算机网络》（B 站，自顶向下方法配套，讲得极清晰）
      • Stanford CS144 Introduction to Computer Networking（https://cs144.github.io/，含自己实现 TCP 栈的 Lab，神级课程）
    • Lab 实践：
      • CS144 Lab（用 C++ 从零实现一个 TCP 栈，8 个 Lab，做完网络理解直接质变）
      • chenshuo/muduo（https://github.com/chenshuo/muduo，C++ 网络库源码，配合陈硕书读）
    • Epoll/Reactor 参考：
      • songwenming/mini-muduo（muduo 简化版，适合学习）
      • 文章：epoll 的本质（掘金/知乎搜，讲得最透的几篇）
    • 参考项目：lvy010/nano-Json-RPC（轻量级 JSON-RPC 实现，可直接对照学习）、lvy010/boost-searcher（C++ 搜索引擎，含网络爬虫部分）
  • 量化验收：
    • RPC 框架：两台机器（或两个进程）能互相调用 add(a, b) 并返回正确结果，支持并发 10+ 连接
    • 能画出 TCP 三次握手/四次挥手状态机，解释 TIME_WAIT 存在的原因
    • 能解释 select / poll / epoll 的区别，为什么 epoll 在高并发下性能更好（O(1) vs O(n)）
    • 能用 tcpdump + wireshark 抓包分析一次 HTTP 请求的完整流程

当你刷完这份路线图，你将不再是纯粹的“数学学生”。你拥有了对计算机底层内存、并发、网络极度敏锐的嗅觉。下午你可以带着这身硬核铠甲，去降维打击大模型了。
