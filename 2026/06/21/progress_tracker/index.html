附录：Python 算法刷题快速唤醒手册 (DSA Warm-up)

1. 数组与字符串：降维打击技巧

Python 的切片和内置函数能让你省掉 80% 的 for 循环。

2. 哈希表 (Hash Map / Set)：最常用的武器

遇到「寻找某个数是否存在」、「统计频率」，无脑用哈希表。

3. 双端队列 (Deque)：BFS 与滑动窗口必备

绝不要用 list.pop(0)！Python 的 list 删头元素的时间复杂度是 O(N)，会超时。必须用 deque。

4. 堆 (Heap)：寻找 Top-K 和最值

Python 只有最小堆，导入 heapq 操作列表。
